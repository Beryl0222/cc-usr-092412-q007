# 超慢跑风险接力

把初筛、医生建议、负荷处方、教练训练记录与异常观察串成**按发生时间排列的个人事件链**，
解决“换场地沿用旧负荷”“补录胸闷没有阻断下一课”“恢复引用旧评估”等风险接力断点。

本仓库是可独立运行的领域服务（无外部依赖）：命令只追加事件，查询由链重放派生。

## 目录

- `contracts/domain.schema.json`：领域事件信封、事件类型与聚合类型约定。
- `src/domain.ts`：领域类型（事件、负荷、角色、分层、教练视图等）。
- `src/errors.js`：错误类型与错误码（`VALIDATION_ERROR` / `AUTHORIZATION_ERROR` / `CONFLICT` / `NOT_FOUND`）。
- `src/rules.js`：纯领域规则——链重放、自动分层建议、处方有效性、教练最小视图、
  课程解释、待办复核、迟到事件影响。无任何 IO。
- `src/store.js`：仅追加 JSONL 事件存储，进程重启重读即恢复，命令串行化、回执幂等。
- `src/service.js`：服务门面，承载资质权限矩阵与全部命令 / 查询。
- `tests/risk-relay.test.js`：20 个场景测试。
- `data/sample.json`：中文样例事件。

## 核心模型

- **个人链**：每个参与者一条 `participant:{id}` 聚合流。事实按 `occurred_at`（发生时间）
  排序重放；`version` 是个人链内的接收序号，单调递增。迟到补录只追加事件，
  **绝不原地改写**历史事件的标识、发生时间或版本。
- **只追加 + 重放派生**：没有可变状态库。服务重启后重新读入 JSONL，
  当前状态、待办复核、课程解释等结论全部可再次推导且一致。

### 角色与签署权限

| 动作 | 护士 | 医生 | 协调员 | 教练 |
| --- | :--: | :--: | :----: | :--: |
| 登记初筛 / 异常观察 | ✓ | | ✓ | 观察 |
| 登记禁忌 | ✓ | ✓ | | |
| 风险分层签署（升级/调整） | | ✓ | | |
| 开具负荷处方 | | ✓ | | |
| 场地交接 | | | ✓ | |
| 紧急停止 | | | ✓ | |
| 暂停 / 复核 / 恢复签署 | | ✓ | | |
| 记录训练完成 | | | | ✓ |

- **自动风险分层只产出建议**（`adviseTier`），不落任何状态；升级、暂停、恢复
  必须由具备资质者签署（`RISK_TIER_SIGNED` / `PAUSE_SIGNED` / `RESUMPTION_SIGNED`）。
- **紧急停止**（协调员）立即把个人链置为 `emergency_stopped` 并作废当前处方，
  阻断一切后续训练。
- **恢复必须引用停止 / 暂停之后完成的“新评估”**（`REVIEW_COMPLETED`）；
  旧评估会被拒绝。恢复后旧处方仍作废，需医生凭新评估重新开方。

### 处方有效性（教练只能执行有效处方）

`canExecute` / 教练开训记录在**课程发生时点**的链投影上同时校验：

- 个人链状态为可训练（非暂停 / 非紧急停止）；
- 处方绑定场地与课程场地一致，且当前时间在有效期内；
- 剩余名额充足；
- 没有未解除的活动禁忌；
- 严重异常观察已经医生复核（未复核直接阻断；中度观察只产生升层建议，不阻断）。

### 数据最小化（教练视图）

`coachView` 与教练时间线只返回执行所需信息：当前场地、状态、负荷、名额、有效期、
以及脱敏后的拒绝结论。筛查事实、病史、禁忌编码与细节、症状、评估原文等临床内容
**一律不返回**；拒绝理由经 `sanitizeForCoach` 脱敏（如“存在未解除的医学限制”）。

### 场地交接（原子迁移）

`transferVenue` 以**单个事件**原子完成：已完成课程保留在历史记录中，
尚未执行的名额与负荷快照随处方迁到新场地；交接后旧场地立即失效，
新场地教练只能执行迁移后的名额与负荷。交接只能由协调员执行。

### 迟到事件与课程解释

- 补录的胸闷 / 禁忌按其 `occurred_at` 进入个人链，晚到的事实会阻断之后的课程判定。
- `lateEventImpact` 回看该事件发生时间之后的处方与训练是否受影响，但**不改写历史**。
- `explainSession` 同时给出：
  - `decision_at_time`：仅依据课程当时已接收的信息，说明为何允许；
  - `late_event_flags` / `late_event_verdict`：迟到补录事实的回看标记与结论；
  - `later_stops`：课程之后发生的紧急停止。

### 幂等

- 同一 `event_id` 重放返回既有事件，不重复落库。
- 设备回执 `device_receipt_id` 在个人链内唯一：网络重试提交**不产生第二次课程、
  不增加运动量**，返回 `{ deduplicated: true, existing_event_id }`。

## 协调员查询

- `explainSession(participantId, sessionId)`：某次课程为何允许 / 为何事后应停止。
- `handoffTrail(participantId)`：谁在何时接手（场地交接、暂停、停止、恢复签署链）。
- `pendingReviews(participantId)` / `pendingAll()`：服务重启后仍待完成的复核与签署，
  如“紧急停止后必须新评估”“等待医生引用评估签署恢复”“恢复后需重新开方”
  “自动建议高于已签署分层，等待医生签署”。

## 本地检查

```bash
npm test     # node --test，20 个场景
npm run build
```

不需要外部服务或数据库；事件默认写入调用方指定的 JSONL 文件路径。

## 领域边界

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。
涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段
（教练角色只获得执行处方所需的脱敏投影）。
