# 超慢跑风险接力

本仓库保存该服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。

## 已有内容

- `contracts/domain.schema.json`：领域事件的基础字段、聚合类型和事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.js`：只负责校验基础事件信封，不包含业务流程。
- `src/events.js` / `src/store.js`：事件类型常量与追加式事件存储（JSONL 持久化、按 `event_id` 幂等、批量原子写入）。
- `src/service.js`：风险接力领域服务（见下）。
- `src/access.js`：角色权限矩阵与教练最小可见视图。
- `tests/`：验证样例与基础约定保持一致，并覆盖风险接力场景。

## 风险接力服务

`RiskRelayService` 以事件溯源方式实现以下规则：

- **个人链**：筛查结论、禁忌、负荷处方、训练完成与异常观察都按发生时间进入参与者个人链；事件不可原地改写，更正只能追加后继记录。
- **处方门禁**：教练只能执行在当前场地且处于有效期限内的处方，准入门禁同时检查紧急停止与签署暂停；允许与拒绝都留下决定记录。
- **自动分层**：筛查或异常观察触发自动分层，但只生成建议事件；升级、暂停、恢复必须由具备资质的人员（医生）签署才生效。
- **紧急停止**：任何在场人员可触发，立即阻断后续训练；恢复必须引用停止之后登记的新评估。
- **迟到事件**：迟到的临床事件不改写历史，而是开启回看复核，列出其发生时间之后可能受影响的处方与课程；复核可完结，待办在重启后依然可查。
- **场地交接**：已完成课程保留在原场地，未执行的名额与负荷随处方原子迁移到新场地（整批写入，失败不落任何事件）；重复设备回执不增加运动量。
- **查询**：协调员可查询某次课程为何允许/停止（`explainSession`）、谁在何时接手（`handoverTimeline`）、待完成复核（`pendingReviews`）；教练视图只含执行必需字段，临床细节仅医生与协调员可见。

## 领域边界

当前资料围绕参与筛查、负荷版本和多源记录整理。事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只读取完成职责所必需的字段。

## 本地检查

```bash
node --test
```

## 测试与构建

测试命令：

```bash
npm test
```

编译或构建命令：

```bash
npm run build
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务。
